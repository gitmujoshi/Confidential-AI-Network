## Primary

Most AI agents never leave the codebase they were built in.

That is fine for summarising a document. It is not how real operations run. The valuable work crosses independent organisations: one party holds the customer relationship, another holds the data, another holds the money, another holds the legal commitment. A model can reason across those steps. It cannot be the system of record for them. It cannot invent a price, skip a consent, or declare a transaction complete.

Andrew Ng is right that the returns sit in redesigning the whole workflow, not speeding up one task. Inside a single software team, that redesign is just another graph of tools. The moment execution has to leave the firm, it hits a wall: there is no shared rulebook the agent can invoke.

That rulebook is an open protocol. Named roles. Standard messages. A published sequence of legal states. The model works at the edges — turning messy intent into a request the network will accept. The protocol works at the core — and refuses illegal jumps.

Credit makes the pattern easy to see. India’s Open Credit Enablement Network (OCEN) is one public spec of it: application, offer, signature, auto-debit. The agent can parse “I have a confirmed order and need working capital in two days.” The network, not the model, advances the loan from one state to the next.

The same split shows up in other multi-party work. A payment is a simple instruction. A loan is a judgment each lender keeps. Identity, consent, and settlement all need a core that is deterministic, and edges that can still be agentic. The lesson is the protocol shape, not any one network.

## Ultra-short

An AI agent can redesign a workflow inside one codebase. It cannot complete that workflow across independent firms unless they share a protocol.

The useful split is simple: the model reasons at the edges; a deterministic open protocol at the core will not let it skip a legal step.

India’s Open Credit Enablement Network (OCEN) is one public example of that shape — not the point of the argument.
