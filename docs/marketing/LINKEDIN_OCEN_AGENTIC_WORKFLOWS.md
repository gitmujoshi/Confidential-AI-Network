## Primary

Agent graphs work inside one repo. They stall when a step has to happen at another company — their data, their signature, their ledger.

Glue in the originator (vendor ids plus flags like “KYC passed”) is not a path the other firm already speaks. Next counterparty, more glue.

What you actually need is a protocol core: one shared object, roles on a registry, named transitions the network enforces. The model emits a request. If it asks to disburse from “offered,” the core refuses. Underwriting, or whatever the judgment is, stays with the party that owns it.

Credit is just the walkthrough in the note. Same shape anywhere the graph leaves the firm.
