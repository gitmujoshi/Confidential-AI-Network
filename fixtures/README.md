# Fixtures

Static JSON samples used by docs, tests, and seed scripts.

| Path | Description |
|------|-------------|
| `contracts/contract_template.json` | JSON Schema for Ricardian contracts |
| `contracts/sample_contract.json` | Example contract payload |
| `test-data/seed-users-data.json` | Seed user output from `scripts/create-seed-users.js` |

Generated test caches (e.g. `test-data-cache.json`) are written to the repo root or `.cache/` during test runs and are gitignored.
