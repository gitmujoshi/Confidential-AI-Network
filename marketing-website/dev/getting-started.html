Quick start

There is no separate SDK. Clone the repository and start the stack.

git clone https://github.com/gitmujoshi/Confidential-AI-Network.git
cd Confidential-AI-Network
./start-system.sh
  • Portal: http://localhost:3000
  • API: http://localhost:5001
  • DEPA gateway: http://localhost:8000
  • Keycloak: https://localhost:8443

npm run status checks health. ./fix-auth.sh repairs a broken Keycloak client.

Source and the full guides are in the repository.
