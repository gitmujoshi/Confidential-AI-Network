Integration Examples

See how easy it is to integrate ContractFlow Pro.

Node.js Example 
const { ContractFlowClient } = require('@contractflow/sdk');

const client = new ContractFlowClient({
  apiKey: 'your-api-key',
  environment: 'production'
});

// Create a new contract
const contract = await client.contracts.create({
  title: 'AI Training Agreement',
  parties: ['provider-id', 'consumer-id'],
  dataSets: ['dataset-1', 'dataset-2']
});

console.log('Contract created:', contract.id);
Python Example 
from contractflow import ContractFlowClient

client = ContractFlowClient(
    api_key="your-api-key",
    environment="production"
)

# Get all contracts
contracts = client.contracts.list()

for contract in contracts:
    print(f"Contract: {contract.title}")
    print(f"Status: {contract.status}")
    print(f"Value: ${contract.value}")
