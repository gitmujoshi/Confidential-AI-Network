What the product does

These are the workflows in the app today. The product tour shows each screen.

Catalog and contracts

A provider publishes dataset metadata. A consumer creates a Ricardian contract against that dataset and a clean-room provider. Training waits until the contract is signed.

Clean-room training

Local training runs on this machine. Azure, Google Cloud, and Oracle jobs go to the cluster that provider already named. AWS does not start a training job.

Differential privacy

A contract can store an epsilon, a delta, and a budget cap. Training refuses an epsilon above that cap.

Consent for personal data

A provider can open an offer. Personal data is returned only after a signed consent artefact still verifies and has not expired or been withdrawn.

Key release

The API accepts a wrapped key and records the release time. It does not store the key bytes. The report stays simulated until a SEV-SNP quote verifies.

Auditor

An auditor opens a sealed Merkle tree for a contract and checks a leaf against that root. The seal is in this database.
