What you can run today

Confidential AI Network is a contract-gated path from a published dataset to a training job and an audit record. The price on that contract is how a data provider is paid for a use they approve, and how a clean-room provider agrees to run that job on capacity they keep. The model owner keeps the model key and a provenance record of the job. The product tour walks the screens.

Why each party joins

The same signed contract is the price, the permission, and the provenance record.

Data providers

A dataset carries a price. After they sign, their dashboard sums that contract value as revenue. Training uses the data they approved. They do not hand the dataset to the model owner. Consent and the privacy budget stay on the contract for the compliance review.

Clean-room providers

A TSP or CCRP monetizes a cluster they already operate by signing the contract that sets the price, the duration, and the environment size. The kubeconfig stays on their provider card. They do not take custody of the dataset or the model key.

Model owners

A TDC trains without receiving the other party’s data, and without putting the model key in the API. The job keeps metrics, the artifact, and a provenance leaf. An auditor can check that leaf against the sealed root for this contract.

Ricardian contracts

A contract binds legal text to the dataset, the model, the purpose, and the clean room. Training starts when the status is SIGNED. Templates live in the repo so a new contract type is a JSON change plus the UI that collects it.

User guide

Clean-room training

Local mode is Docker, native PyTorch, or MLX. Azure, Google Cloud, and Oracle submit to the cluster already named on the contract and the provider card. AWS returns 501 and does not write a job. The runner code is under training/.

Training runtime

DEPA /v1 gateway

Port 8000 accepts the DEPA-shaped calls and forwards them to the CAN API. Contract creation, a differential-privacy budget, offers, consent, release, and provider listing are on that surface. The gateway is a façade, so a new DEPA route is a translation, not a second database.

DEPA /v1 API

Differential privacy budget

A contract can store epsilon, delta, and a budget cap. The trainer rejects an epsilon above that cap. The Docker runner receives the cap. This is a control on the job, not a claim that every model on the platform is differentially private.

API reference

Consent for personal data

A provider opens an offer. Personal data is returned only while the signed consent artefact still verifies and has not expired or been withdrawn. Ordinary responses omit that payload.

Compliance

Keys and signing

Key release records the time and rejects raw key bytes. Signing keys stay in the database until SIGNING_KEY_BACKEND is azure-keyvault or azure-mhsm. That path creates the key in Key Vault and verifies before it accepts the signature.

Security

Auditor Merkle tree

An auditor opens the sealed tree for a contract and checks a leaf against the published root. The proof is for lineage of that contract, the job, and the recorded evidence. It is not a statement that the model was fair or accurate.

Product tour

Deploy where you already have a cluster

Local secrets stay in secrets.env. A cluster reads Key Vault, Secret Manager, Secrets Manager, or OCI Vault. The deployment hub lists every common setting and the extra inputs for each cloud. A missing kubeconfig fails the job.

Deployment

Where to contribute

Pick a surface, run it, and send a change. Write to hello@dpi-apps.space if you want a place to start.

Portal and API

React on port 3000 and Express on port 5001. Role dashboards, contract signing, and the auditor view are the UI. Jest covers the API.

Training and attestation

Runners for local Docker, native, MLX, AKS, GKE, and OKE. The Azure guest-report collector fails when the node has no SEV-SNP interface. The job stays simulated until that report verifies.

Identity and secrets

Keycloak locally, Entra on Azure. External Secrets syncs Key Vault into the cluster and stays off until you install it. The secrets guide says which file is local and which store is for a cluster.
