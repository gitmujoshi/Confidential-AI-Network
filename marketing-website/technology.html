How it is built

The portal, the API, and the DEPA gateway are three processes. The gateway translates /v1. It is not a separate orchestrator.

Portal

React on port 3000. People sign in with Keycloak and work in a role dashboard.

API

Express on port 5001. Contracts, training, consent, and audit live here. PostgreSQL stores the records.

DEPA /v1

The gateway on port 8000 maps /v1 calls onto the same API. Organization credentials, a SEV-SNP quote, and consent offers are checked on that surface.

Identity

Local sign-in is Keycloak at https://localhost:8443. A job’s attestation report stays simulated until a SEV-SNP guest report verifies against the pinned ARK.

Details are in the architecture guide and the API reference.
