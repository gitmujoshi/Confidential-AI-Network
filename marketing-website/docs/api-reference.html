API reference

The portal calls /api on port 5001 with a Keycloak bearer token. DEPA clients call /v1 on port 8000. The gateway translates those calls. It does not run a second product.

Portal

  • GET /api/health reports the API.
  • Contracts, datasets, training, and audit use the signed-in user’s role.
  • POST /api/can/jcs/jobs/:id/key-released takes keyType, attestedPublicKey, and wrappedKey. The response has keyStored: false. A raw key field is rejected.

DEPA /v1

  • POST /v1/contracts uses datasetIds, or a templateId that matches a public dataset’s template hint.
  • POST /v1/scenarios/{contractId}/dp-config saves epsilon, delta, and a budget cap.
  • POST /v1/offers, then consent, release, and withdraw. Release returns personal data only while the signed artefact still verifies.
  • GET /v1/providers?type= lists Data Consumer, Key Management, Contract Management, and Identity Management parties.
  • POST /v1/ccr/{id}/attestation stores a SEV-SNP quote only when the guest report verifies. Otherwise the mode stays simulated.
